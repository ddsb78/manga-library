## 2.7.9 更新

- 修复三民 `pi` 页码、文化传信分页默认参数、大辣目录默认分类导致的跨页草稿分裂。返回前页、取消勾选和刷新共用同一目录草稿；新出现的商品不会自动勾选。
- 适配青文实际多层目录与动态换页，勾选按钮避开商品链接；修正文化传信导航与商品卡片同名时入口放错位置的问题。
- 修复大辣目录标题漏读，以及“下一页”误取省略号跳页的问题；修复 d/art 目录漏读、集英社新版纸书标题链接、小学馆新版数据结构与动态分页、讲谈社“加载更多”后的勾选入口。兼容东立实站 `Bd` 商品参数。
- 文化传信同一商品页的“书目名称／期数”组合可以分别采集。“本地漫画珍藏专区”实站页面识别为 **6 个书目／版本、36 个组合**，普通版与限量硬皮版分组保留；采用每个组合自身的封面、册号和价格。这个数量只表示当前页面选项，不表示完整出版套数。

文化传信多书目页：展开工具箱，在“查看 / 调整卷册选择与逐本资料”的“书目 / 版本”中筛选，再勾选所需册号。切换筛选保留勾选，取消与刷新也保留；页面自带购买下拉框和工具箱勾选独立，导出以工具箱所选条目为准。脚本用 `bcd_variant` 参数保存原站变体 ID；原站不会因此自动切换购买下拉框。页面没提供的 ISBN、作者与简介留空，需人工补录；不将整页默认简介套给其他作品。没有 ISBN 也可导出本地建档 ZIP，XLSX 无书号行不能自动按 ISBN 联网搜书。

## 2.7.8 更新

- 修复博客来点击原站“下一頁／上一頁”后跨页勾选丢失：原站会重排网址中的 `page`、`spell` 等路径参数，现在按搜索参数识别同一目录，页码和显示模式共用勾选草稿。
- 支持博客来原站 `rel="change_page"` 的下一页链接，工具箱“加载下一页书目”也可使用；新载入书目仍需自行勾选。
- 升级时恢复当前地址对应的旧草稿。旧版已拆开的多个草稿不会自动汇总；需要重新勾选遗漏项。已有新版草稿优先，已取消的勾选不会被旧草稿覆盖。

博客来可直接使用网页上的“下一頁／上一頁”：第 1 页勾选、第 2 页继续勾选，右下角显示累计数量；返回前页可继续修改。工具箱“查看 / 调整卷册选择与逐本资料 → 仅看已选卷册”可核对跨页选择。草稿有效期为 24 小时，单个目录最多累计 300 项；关键词或筛选条件改变时使用不同草稿。

## 2.7.7 更新

- 勾选按钮更紧凑，统一未选、已选、悬停与键盘焦点样式。全选本页、全部取消、分页与刷新本页放在常用区，合集选项折叠收纳；卷册列表新增“仅看已选卷册”。
- 修复诚品大图模式没有勾选入口的问题，兼容列表与大图卡片；勾选控件位于商品链接外，选择时不会打开商品。
- 有明确下一页链接的目录支持“加载下一页书目”，一次加载一页；已有勾选保留，新载入书目需自行选择。新增页的书目在工具箱中核对，不自动读取未选择商品的详情。
- 诚品使用原站分页按钮，可“前往下一页 · 保留已选”；切换显示模式与翻页保留草稿，换关键词或筛选目录时隔离草稿。
- 出版社现有作品目录增加统一勾选入口，沿用默认收起的工具箱与核对、导出流程。

## 使用步骤

1. 浏览器先安装 Tampermonkey（篡改猴）或 Violentmonkey（暴力猴）。
2. 点击上方安装／更新链接，覆盖原书库采集脚本，只启用一份。若只显示文本，可在油猴中用此链接导入，或复制全部内容替换旧脚本并保存。已安装者也可在油猴中检查更新。
3. 刷新书店搜索页，勾选卷册；需要读取或导出时展开右下角工具箱。翻页后保留选择，缺的册可粘贴本站商品链接。核对统一作品名、卷号和版本后导出。
4. 建档 ZIP 在电脑“我的书库 → 导入本地建档包”中预览入库；XLSX 用于“搜书 → 导入 ISBN 搜书清单”。

金石堂、三民、诚品、博客来与 TAAZE 读册生活支持搜索勾选，与工具箱同步。搜索页默认不选，勾选后再读取、核对；搜索结果数与累计载入数量不代表作品总卷数或全套完整。

读册生活支持中文纸书商品及搜索页，列表和大图模式均可逐册勾选；二手结果按原书目读取，与新书同册去重，不将不同二手报价当作多卷。商品没有的资料保留待核对。另支持豆瓣及脚本列明的出版社；限制级或验证页面由用户自行登录后采集。
