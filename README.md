# 漫画书库

漫画书库fast 的下载发布仓库，提供 Windows 电脑端与 Android 手机端安装包。

[前往 Releases 下载](https://github.com/ddsb78/manga-library/releases)

- Windows：下载带 `windows-x64-setup.exe` 的文件，运行安装或原位升级。
- Android：下载带 `android.apk` 的文件，在手机安装或覆盖升级。
- 文件校验值随版本提供，升级前建议在电脑端保存书库备份。

电脑首次使用可查看逐页图解，也可以跳过。首次新书资讯采集需要先设置范围，并点击“保存设置并开始采集”。手机通过电脑“设置 → 手机同步”的二维码配对，在同一 Wi-Fi 下同步，下载后可离线浏览。

本仓库只提供安装包、下载说明与版本说明，不包含项目源代码、个人书库或账号资料。GitHub 自动生成的 Source code 压缩包只是本仓库说明文件，安装请使用 Release 附件中的 EXE 或 APK。
