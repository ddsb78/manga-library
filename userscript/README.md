# 漫画书库fast · 油猴脚本

当前版本：**2.7.5**

[安装／更新脚本](https://raw.githubusercontent.com/ddsb78/manga-library/main/userscript/books-cover-jpg.user.js)

金石堂、三民、诚品、博客来的搜索结果都能逐册勾选，与右侧工具箱同步。搜索页默认不选，勾选后再读取；支持多册合成一个作品，也可以粘贴缺少的商品链接。

1. 浏览器先安装 Tampermonkey（篡改猴）或 Violentmonkey（暴力猴）。
2. 点击上面的安装／更新链接，覆盖原书库采集脚本，只启用一份。若浏览器只显示文本，可在油猴中用此链接导入，或复制全部内容替换旧脚本并保存。
3. 刷新书店搜索页，勾选需要的册数，再读取、核对并导出。选择本身不会开始查询。
4. 建档 ZIP 在电脑“我的书库 → 导入本地建档包”中预览入库；XLSX 用于“搜书 → 导入 ISBN 搜书清单”。

支持金石堂、三民、诚品、博客来、豆瓣及脚本列明的出版社站点。限制级或验证页面由用户自行登录后采集。

此页面只更新油猴脚本，无需重装电脑或安卓。后续版本沿用同一链接，油猴可从该地址检查更新；检查频率由扩展设置决定。电脑帮助页随安装包携带的脚本可能较旧。
