# 漫画书库fast · 油猴脚本

当前版本：**2.7.6**

[安装／更新脚本](https://raw.githubusercontent.com/ddsb78/manga-library/main/userscript/books-cover-jpg.user.js)

新增 TAAZE 读册生活：搜索结果可逐册勾选，支持列表和大图模式、补商品链接、多册合成作品和带封面导出。新书与二手搜索结果按原书目去重。

金石堂、三民、诚品、博客来同样支持搜索勾选，与右侧工具箱同步。搜索页默认不选，勾选后再读取、核对。

1. 浏览器先安装 Tampermonkey（篡改猴）或 Violentmonkey（暴力猴）。
2. 点击安装／更新链接，覆盖原书库采集脚本，只启用一份。若只显示文本，可在油猴中用此链接导入，或复制全部内容替换旧脚本并保存。
3. 刷新书店搜索页，勾选卷册；缺的册可粘贴本站商品链接。核对统一作品名、卷号和版本后导出。
4. 建档 ZIP 在电脑“我的书库 → 导入本地建档包”中预览入库；XLSX 用于“搜书 → 导入 ISBN 搜书清单”。

读册生活当前支持中文纸书商品与搜索页，二手结果读取原书目。商品没有的资料保留待核对。另支持豆瓣及脚本列明的出版社；限制级或验证页面由用户自行登录后采集。

此页面单独更新油猴，无需重装电脑或安卓。固定链接可用于油猴检查更新；电脑帮助页随安装包携带的脚本可能较旧。
